# my-blog-back-app

Бэкенд веб-приложения «Блог». Предоставляет REST API для фронтенда: посты, теги, лайки, картинки и комментарии.

## Стек

- Java 21
- Spring Framework 6.2 (Spring Web MVC, Spring JDBC) без Spring Boot
- H2
- Maven, сборка в `war`
- Apache Tomcat 10.1
- JUnit 5, Spring TestContext Framework

Подробная инструкция по сборке и запуску будет добавлена по мере разработки.
